# Analyse de sentiment d'avis clients

Application web qui classe automatiquement un avis en **positif** ou **négatif**
grâce au Machine Learning (Scikit-learn), entraînée sur des avis Allociné en français.

🚧 Projet en cours de construction.

## Lancer le projet

    python -m venv .venv
    pip install -r requirements.txt
    python explorer.py
